# Capturas de los menús — para rellenar cuando llegue la cámara

La a6700 no tiene función de captura de pantalla, y las imágenes del manual
de Sony tienen derechos: no se copian aquí. Este directorio es para **tus
propias fotos de las pantallas**, que además saldrán en tu idioma y con tus
valores.

**Cómo hacerlas** (media hora, una vez):

1. Cámara encendida, menú abierto en el ajuste, **con el valor ya puesto**.
2. Foto con el móvil, de frente y sin reflejos (apaga la luz de arriba).
3. Recorta a la pantalla y guarda aquí en JPEG, lado largo ~1200 px.

**Nombres** (en kebab-case, el del ajuste tal cual sale en el menú):

```
rec-motivo-af.jpg        dest-reconocim.jpg      area-de-enfoque.jpg
sens-seguim-af.jpg       modo-manejo.jpg         tipo-de-obturador.jpg
iso-auto-limites.jpg     visualizac-cebra.jpg    rr-exposic-larga.jpg
func-capt-interv.jpg     mem-ajustes-cam.jpg     ajuste-t-pers-dial.jpg
```

**Cómo se pegan** en `referencia/ajustes-a6700.md`, junto a su fila:
